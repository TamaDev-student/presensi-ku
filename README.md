# Presensi Ku

Aplikasi presensi berbasis Flutter dan Firebase. Aplikasi ini memungkinkan pengguna untuk melakukan presensi dengan mudah menggunakan perangkat seluler mereka. Dengan fitur-fitur seperti autentikasi pengguna, pencatatan waktu, dan integrasi dengan Firebase, aplikasi ini memberikan solusi yang efisien untuk manajemen presensi.

## Fitur Utama
- Autentikasi pengguna menggunakan Firebase Authentication.
- Pencatatan waktu presensi secara real-time.
- Integrasi dengan Firebase Firestore untuk menyimpan data presensi.
- Antarmuka pengguna yang responsif dan mudah digunakan.

## Teknologi yang Digunakan
- Flutter: Framework untuk pengembangan aplikasi mobile.
- Firebase: Platform backend untuk autentikasi dan penyimpanan data.
- Dart: Bahasa pemrograman yang digunakan dalam pengembangan aplikasi Flutter.
- Git: Sistem kontrol versi untuk manajemen kode sumber.
- GitHub: Platform untuk hosting dan kolaborasi kode sumber.


## installasi1. Pastikan Anda memiliki Flutter SDK terinstal di komputer Anda. Anda dapat mengunduhnya dari [situs resmi Flutter](https://flutter.dev/docs/get-started/install).
2. Pastikan Anda memiliki akun Firebase dan telah membuat proyek Firebase untuk aplikasi Anda. Anda dapat melakukannya di [Firebase Console](https://console.firebase.google.com/).
3. Pastikan Anda memiliki editor kode seperti Visual Studio Code atau Android Studio yang mendukung pengembangan Flutter.
4. Pastikan Anda memiliki koneksi internet yang stabil untuk mengunduh dependensi dan mengakses layanan Firebase.
5. Pastikan Anda memiliki perangkat fisik atau emulator yang dikonfigurasi untuk menjalankan aplikasi Flutter.
6. Pastikan Anda memiliki akses ke terminal atau command prompt untuk menjalankan perintah Flutter.
7. Pastikan Anda memiliki pengetahuan dasar tentang Flutter dan Firebase untuk memahami kode dan konfigurasi yang diperlukan untuk menjalankan aplikasi ini.
8. Pastikan Anda memiliki akses ke file `google-services.json` yang diperlukan untuk mengkonfigurasi Firebase dalam proyek Flutter Anda. File ini dapat diunduh dari Firebase Console setelah Anda menambahkan aplikasi Android ke proyek Firebase Anda.
9. Pastikan Anda memiliki akses ke file `Info.plist` yang diperlukan untuk mengkonfigurasi Firebase dalam proyek Flutter Anda untuk platform iOS. File ini dapat diunduh dari Firebase

## Cara Menggunakan
1. Clone repositori ini ke lokal Anda.
2. Buka proyek di editor Flutter favorit Anda.
3. Jalankan perintah `flutter pub get` untuk menginstal dependensi.
4. Konfigurasikan Firebase untuk aplikasi Anda dan tambahkan file `google-services.json` ke dalam proyek.
5. Jalankan aplikasi menggunakan perintah `flutter run`.

## cara commit1. Pastikan Anda berada di direktori proyek Anda di terminal atau command prompt.
2. Gunakan perintah `git add .` untuk menambahkan semua perubahan yang telah Anda buat ke staging area.
3. Gunakan perintah `git commit -m "Pesan commit Anda"` untuk membuat commit dengan pesan yang menjelaskan perubahan yang telah Anda buat.
4. Gunakan perintah `git push origin nama-branch` untuk mengirim commit Anda ke repositori remote di GitHub. Gantilah `nama-branch` dengan nama branch yang sesuai dengan alur kerja Anda, seperti `main` atau `master`.
5. Setelah Anda melakukan push, perubahan Anda akan terlihat di repositori GitHub dan dapat diakses oleh anggota tim atau publik, tergantung pada pengaturan privasi repositori Anda.
